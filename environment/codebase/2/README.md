# Codebase 2 — Palindrome check

**Difficulty: 2/5 (easy)**

`is_palindrome` reports whether a string reads the same forwards and backwards,
ignoring case and non-alphanumeric characters.

## Expected behaviour

- `is_palindrome("racecar")` is `True`
- `is_palindrome("abba")` is `True`
- `is_palindrome("ab")` is `False`
- `is_palindrome("abca")` is `False`
- `is_palindrome("A man, a plan, a canal: Panama")` is `True`
