# Codebase 1 — Temperature converter

**Difficulty: 1/5 (trivial)**

Two small helpers convert temperatures between Celsius and Fahrenheit.

## Expected behaviour

- `celsius_to_fahrenheit(0)` == `32`
- `celsius_to_fahrenheit(100)` == `212`
- Round-tripping a value returns the original temperature.

## Run the tests

```
python -m pytest
```

There is exactly one bug. Fix it so the tests pass.
